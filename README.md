# Code: Terraform

[**Code: Terraform**](https://store.steampowered.com/app/868160/Code_Terraform/) is an automation and programming video game on Steam where you use real Python-like scripts instead of traditional buttons or drag-and-drop interfaces to revive a frozen alien planet.

## Core Gameplay

### Write Real Code

Every action in the game is controlled through code. You can write scripts to:

* Drive rovers
* Mine resources
* Adjust solar panel tilts
* Manage power grids
* Dispatch drone fleets
* Automate planetary infrastructure

The game provides an in-game editor, console, and documentation to help you develop and execute your scripts.

### Continuous Automation

Your scripts run continuously in the background while you plan your next move and build interconnected infrastructure.

This allows you to create automated systems that can manage resources, vehicles, energy, and other planetary operations without manually controlling every action.

### Planetary Response

As your automation and terraforming efforts succeed, the alien planet responds and evolves.

Your progress affects both the environment and the in-game narrative as you gradually transform the frozen planet.

### External Editor Support

**Code: Terraform** supports external code editors, allowing you to use tools such as:

* [Visual Studio Code](https://code.visualstudio.com/)
* [Zed](https://zed.dev/)
* [PyCharm](https://www.jetbrains.com/pycharm/)

External editor support provides features such as:

* Autocomplete
* Debugging
* Advanced code navigation
* Script management
* A more familiar development environment

## Getting Started

The game provides an in-game programming environment and documentation to help you learn the available APIs and automate the various systems on the planet.

The basic gameplay loop is:

```text
Write Code
    ↓
Execute Script
    ↓
Automate Systems
    ↓
Collect Resources
    ↓
Build Infrastructure
    ↓
Terraform the Planet
    ↓
Improve Automation
    ↺
```
